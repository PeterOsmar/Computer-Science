1. A+: A high-level, interactive, interpreted array programming language designed for numerically intensive applications, especially those found in financial
       applications
       (A+ deposit: https://github.com/PlanetAPL/a-plus)
2. ABAP (Advanced Business Application Programming): A domain-specific high-level programming language created by the German software company SAP SE
                                                     (ABAP learning site: https://learning.sap.com/courses/basic-abap-programming)
3. ABC: An imperative general-purpose programming language and integrated development environment (IDE) developed at Centrum Wiskunde & Informatica (CWI), in
        Amsterdam, Netherlands by Leo Geurts, Lambert Meertens, and Steven Pemberton
        (ABC learning site: https://homepages.cwi.nl/~steven/abc/programmers/introduction.html)
